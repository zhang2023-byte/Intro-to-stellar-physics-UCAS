# 全课符号约定

制作和修订共用。符号跟随原版教材（Böhm-Vitense，Vol. 2）；原书一个符号身兼两义时，按下表拆开。新增跨章符号先查本表，表中没有的在首次出现处定义，并在 PR 说明里提出补表。

正文按本表写时不必再解释“别的资料怎样记”；只有学生会读到的另一套记法（例如《当代天体物理学导论》的质量不透明度）才在首次出现处用一句话对照。

## 吸收与不透明度

| 符号 | 含义 | SI 单位 | 说明 |
|---|---|---|---|
| κλ、κν | 每单位路径长度的吸收系数 | m⁻¹ | 原书默认含散射。dτλ=κλ ds，κλ=∑ nᵢσᵢ |
| κc、κL | 连续谱、谱线的单位长度系数 | m⁻¹ | 同一波长的总系数为 κc+κL |
| κλ,abs、κλ,sc | 真吸收、散射部分 | m⁻¹ | 只在需要区分时使用，κλ=κλ,abs+κλ,sc |
| σ | 单个粒子的截面 | m² | 下标写粒子或过程：σ(H⁻)、σel（Thomson）、σR（Rayleigh） |
| κR、κF、κe | Rosseland 平均、通量平均、电子散射的质量不透明度 | m² kg⁻¹ | 原书 κgr=κcm/ρ（式 9.8）。对应的单位长度量写 ρκR |
| κ/H、κ per heavy particle | 每个氢原子或重粒子的吸收 | m² | 仅在读原书图表时使用，写清“每个……” |

不使用 α 表示吸收系数；α 留给角半径（第 3 章）、Voigt 阻尼参数（第 10 章）、幂律指数等，并在所在章内定义。

## 其他跨章符号

| 符号 | 含义 | 说明 |
|---|---|---|
| F、Fλ | 单位面积的实际净能量流率，W m⁻² | 原书写 πF；本课把 π 并入 F，首次出现时说明一次。第 14 章现用 ℱ，下次修订时统一为 F |
| ελ、εν | 发射系数（单位体积、立体角、波长或频率的功率） | Sλ=ελ/κλ。第 13 章把受激发射并入 κ′ν 后，只含自发发射的系数写 ην |
| σSB | Stefan–Boltzmann 常数 | 与截面 σ 区分，不写成单独的 σ |
| Θ | 5040/T（T 以 K 计） | 原书常用缩写，χ 以 eV 计时 log₁₀ e^(−χ/kT)=−χΘ |
| τλ、τR | 单色光学深度、Rosseland 平均光学深度 | dτR=ρκR dz |

# 课件讲解写法

制作新课、修订讲解、重写整节或整章时使用本文件。目标读者已学过辐射与热统，但恒星大气对他们是新领域。读完一节后，他们应能说出这一节要解决什么问题、结论怎样一步步得出，以及关键数字的量级。

范本是 `lessons/v2-ch07.md`（1.2.0）。动笔前先读它的 #contributors 和 #hot-stars 两节，看驱动问题、逐步计算和对照表是怎样配合的。

## 常见失败方式

模型生成的课件最常见的问题，不是内容错，而是写成了给审稿人看的摘要：

- 句子准确，但压缩。一句话同时放结论、条件和例外，推理链留给读者自己补。
- 用抽象名词代替物理过程。例如“提供可计算的基准”“把 X 接到 Y 上”“承担不同任务”，读者看不出哪些光子、哪层气体发生了什么。
- 每个结论后面跟两三条“不能／不等于／还须核对”，主线被淹没。
- 版本差异、记号约定和勘读说明写进正文。
- 公式写出来了，却不代入数字；推导只写“代入……得到”。
- 交互说明先替学生说出读数。习题解析只复述正确规则。

下面的规则逐条对应这些问题。

## 动笔前的小节提纲

每节先在 HTML 注释中写出六项，再写正文：

1. 驱动问题：本节回答的一个具体问题。
2. 物理图像：用一两句话描述正在发生什么。
3. 关键关系和推导步骤。
4. 至少一个算例：先回到原版教材，找它对相同问题做过的估计，按原书条件重算。
5. 承接：用到前面哪个结果，结果又在后面哪里用到。
6. 唯一保留在正文的限制条件：不写会让学生算错或判断错的那一条。

## 段落写法

- **小节用问题或具体现象开头，不用定义开头。**
  - 前：“吸收截面表示一个粒子对特定频率光子的有效吸收面积。”
  - 后：“先要有一个量来描述‘一种粒子吸收得多强’。把每个粒子想成光子路径上的一个小靶子……”
- **新物理量先讲它描述什么，再给公式。** 公式后先说它告诉我们什么，最后用一句话交代符号和单位。
- **一段只讲一个意思。** 超过约 200 字，或同时包含定义、算例、推导和例外，就拆开。
- **修订时重写整段，不往段落里追加。** 往原段落里加内容会让段落越来越密，重点被推到段尾。
- **机制写成“谁对谁做了什么”。**
  - 前：“该过程近似弹性，不等于同等能量已经热化。”
  - 后：“光子只是被转了个方向，能量还在辐射场里。”
- **概括句后面必须紧跟具体内容。** 只做概括、没有内容跟上的句子删掉。下列说法是需要改写的信号：提供……基准、入口或条件；把……接到……；承担……任务；使……可检查；为……铺路。
- **类比要说明对应哪个物理量。** 例如“弹簧的固有频率就是原子的共振频率”。
- **首次出现的术语给中文名、英文名和一句定义。** 跨章符号按 [notation.md](notation.md)；学生会读到的其他资料记法不同时，在首次出现处用一句话对照。

## 公式、推导与数字

- **每个核心关系至少代入一次数字。** 数值要能让学生感到量级，例如“kT≈0.52 eV，10.2 eV 约为 kT 的 20 倍”。优先使用原书的条件和数字。
- **心算 30 秒内补不出来的步骤要写出来。**
  - 前：“将幂律代入静力方程……得到”
  - 后：写出 Pⁿ dP=(g/C)dτ，再写积分结果。
- **长推导放进 `<details>`。** 摘要写“推导：……”，正文只保留结论和一句理由。
- **比较量级时写出算式。** 例如“3×10⁻⁸/6×10⁻¹⁰≈50”。只写“远大于”，学生无从核对。
- **重算结果与原书不同时**，正文写自己的数字，并用“原书取整为……”带过。差异的说明集中放进本章最后一个“核对原书数字”折叠块。

## 限制条件

- **每段最多保留一条限制。** 选会让学生算错或判断错的那一条。
- **其余限制的去处。** 合并成小节末尾的一句“适用范围”，或者放进折叠块。纯记号约定只在首次出现时说明一次。
- **用正面陈述写限制，并给出理由。**
  - 前：“不能把温度序列简单当成单一组分的丰度序列。”
  - 后：“本章数字都是特定温度和电子压强下的估计，换一颗星要重算。”
- **正文不写给审稿人看的话。** 例如“本课采用……”“本页不把……写成……”“原书某处排版与量纲不一致”。版本差异和勘读放进折叠块或本机过程记录；仍待核实的事项记在过程记录里，不写进学生正文。

## 交互说明

按三步写：

1. 先让学生预测，用一句问句提出。
2. 告诉学生改变什么量、看哪个读数。
3. 操作之后解释现象，并接回正文的关系。

不要在学生操作之前给出具体读数。模型假设由组件说明负责，正文最多用一句话提醒“曲线只看趋势”。

## 习题与解析

- **判断题解析的写法。** 按 FORMAT，解析以“该说法成立／不成立”开头，接着给出依据，再说明这个错误想法为什么诱人：学生会想到什么，漏掉了什么。
- **选择题解析的写法。** 先写正确推理，再逐个说明错项对应的真实误解。常见误解包括：漏乘一个因子、方向弄反、套错近似、把局部关系当成整体结果。不要使用没有人会选的干扰项。
- **至少一题考应用。** 要求在新条件下用正文的方法算出一个数，或判断一个趋势。

## 自检

1. 运行 `./tools/course prose <ID>`，按学生阅读顺序通读输出。
2. 运行 `./tools/course style <ID>`，逐条处理报告的信号。确有必要保留的，在过程记录里说明理由。报告只是提示，不代替通读。
3. 对每一节回答三个问题：
   - 驱动问题是什么，答案能不能用一句话说出？
   - 算例能不能照着重算出来？
   - 用到前文哪个结果，是否给了链接？
4. 对每道题回答：每个错项代表什么误解？

答不上来的地方，修改正文。

## 整节或整章重写

- **准备。** 先读本文件、范本章，以及原版教材的对应章节。原书的估计和例题通常是最好的算例来源。
- **保持稳定。** 保留小节、活动和题目 ID。按小节提纲逐节重写，不在旧段落上修补。改动题干或答案时，按 FORMAT 升 minor 版本。
- **交付对照。** 给出各节的新旧片段，并附三项指标：正文字数、“不能”类告诫的次数、具体数值的个数。对照稿放在本机过程记录中。

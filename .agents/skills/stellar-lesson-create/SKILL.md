# 制作恒星物理课件

先读项目 AGENTS.md；教材读取按 textbooks/pdf/README.md，源码格式与命令按 tools/FORMAT.md。此流程用于助教新建课程；修订任务只按需引用下文教学质量要求，不执行整套制课步骤。

1. 明确教材范围、学习目标和学生基础；默认采用 AGENTS.md 中的基础。缺少教材范围时向助教确认，不自行决定课表。
2. 读取对应原版与译本 PDF，核实关键公式、数字、图表和适用条件。书名、版本、小节及实际核实的印刷页码或 PDF 页序记在本机过程记录中；学生网页的教材定位按 tools/FORMAT.md 编写。不确定处记录缺口。
3. 按 FORMAT 新建 lessons/<ID>.md。以 Volume1–3 为主线，Ref 的补充解释放折叠卡片；正文保留核心概念、定量关系、推导入口和适用条件，习题统一置于章末。未得到材料支持的前沿判断不写成结论；只有有教学价值的具体缺口才设置开放调研。
4. 按下文组织解释、题目和原创图示。数字曲线与示意曲线明确区分，在图旁说明模型假设、单位、归一化及非观测性质。需要时扩展共用交互，不让现有模板限制教学内容。
5. 构建本课；共用组件变化时全站重建。执行 FORMAT 中的一致性检查、工具测试及下文制作验收，确认在线页面的公式、交互、全部题目、窄屏和反馈入口。反馈入口检查不等于真实问卷提交成功。
6. 交付源码、HTML、核实范围和未完成项。按 AGENTS 中的授权边界处理 Git 交付，不在收尾自动启动规则复盘。

只有助教明确安排教材并行调研时，才使用子代理：gpt-5.6-luna、max、全新上下文，至多三个并发，各写分配文件，不再派生；主代理合并验收。环境不具备此能力时说明，由助教决定替代方式；普通任务不以此为前提。

## 知识组织与表达

课程标题和小节标题直接写物理主题或准确的概念名称，使学生从标题判断内容。避免含糊的问题、悬念和口号。例如，涉及相应内容时可用“光度、辐射通量与星等”；“看到的亮代表什么”指向不清。标题须与实际教材范围一致。

开头用简短段落交代本课研究什么、为什么需要这些知识，并列出本课涉及的核心知识点。随后说明知识点之间的关系和讲解顺序，使学生知道哪些概念提供基础、哪些关系用于推导、哪些内容用于解释或应用。不要把概念名称清单当作整堂课的讲解。

每个知识点先用直白的语言说明含义及它解决的具体问题，再结合需要给出例子、图示、公式和推导。说明本节如何承接前文、所得结果如何用于后文；这些关系应自然写进正文，不必机械重复固定栏目。必要的新术语首次出现时解释，公式说明符号、单位、物理含义和适用条件。依据教师指定的基础保留应有深度。

交互围绕正在解释的物理关系安排，交代改变什么量、观察什么变化，以及变化如何帮助理解该关系。是否先观察再解释由具体知识点决定。核心概念和必要联系写在连续阅读的正文中；补充推导与 Ref 解释放折叠卡片。

正文和答题解析使用以下表达原则：一个段落讲清一个主要意思，用具体、准确、连贯的表达。列表用于确有并列或顺序的内容。删去装饰性文字、套话、自问自答、刻意对比和生造标签，同时保留必要解释。

交付前从学生角度通读：仅看标题能否判断主题；读开头能否说出核心知识与学习目的；读正文能否解释各概念及其关系、说明为什么按此顺序讲解；公式和交互是否得到解释。把无法回答的位置改清楚。构建和显示检查通过后，仍需完成这项教学检查。

## 制作与验收

写正文前，在课程源码的 HTML 注释中维护简短编写提纲，列出核心知识、前置知识及本节结果在后文的用途。先检查概念是否突然出现、解释是否重复、必要联系是否缺失，再安排正文和交互。学生开头读到自然的课程介绍；编写提纲不在页面显示。

每个交互说明改变的量、观察的量和需要理解的物理关系，验收时实际操作并核对现象与解释。交互数量由内容决定。必要的概念解释不能只藏在活动或折叠卡片中。

章末解析说明正确答案的推理依据，并指出各错误选项的具体误解，关联正文概念、公式或适用条件。验证答错后可更改选项并重新提交。按核心理解的需要使用与正文例子不同的情境，检验能否应用已讲的关系，保持题目条件充分。

完成后逐项核对核心知识：正文位置、前置解释、前后关系、需要检验的理解及对应题目。将检查结论记入本次验收材料，不在学生正文放教学管理表格。题目数和交互数不能代替覆盖检查。

浏览器验收补充键盘完成交互与答题、焦点可见、文字放大后的内容可读性，以及图表是否有颜色以外的标识。记录实际检查范围和发现的问题；只通过自动检查时，不声称人工或学生试读通过。

## 反馈中反复出现的理解障碍

- 关键且易混淆的术语首次出现时补英文及一句定义。核对教材实际用词；补充的同义术语注明是补充，不能让学生误以为它就是原文。遇到不同译名，先比较定义、单位和适用条件。
- 引入零点、系数或新关系时，说明它由什么决定、怎样确定、与前文如何相连；必要时给一个标明单位或归一化约定的简短算例。一个符号在不同资料中定义不同时，将理解题目所需的区别放在正文及题干中。
- 正文、表格、题干、选项、解析和活动读数统一数学符号。上下标、分数和科学计数法以实际渲染验收；手机端长公式优先合理分行。使用当前构建工具支持的格式，避免在题目纯文本字段中直接写HTML。
- 判题结果说明学生是否答对，解析说明命题是否成立；避免“回答正确。判断错误。”。提示提供文字和可辨认标志，不能只靠颜色。
- 章末习题按知识联系安排少量跨章应用，说明所用的前置概念与适用条件；不为凑题数重复已有题目。解释新术语时先说明它解决什么问题，再给定量关系。

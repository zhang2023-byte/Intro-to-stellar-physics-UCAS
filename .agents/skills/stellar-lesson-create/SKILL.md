# 制作恒星物理课件

使用项目 `AGENTS.md` 和 `tools/FORMAT.md`。已有课件的反馈修订使用另一 skill；不要重做整个课程系统。

1. 明确教材范围和学习目标。用户未给课时或学生基础时采用适合本科基础课的深度并说明假设；缺少教材范围时只问这一项，不自行决定正式课表。
2. 查 `mapping/catalog.md` 和对应卷表，从真实入口读取 MinerU 正文。候选对应只是导航，必须读双方正文。译文用于术语与理解，不作为独立证据。核对关键公式、数字、图表与差异判断的拆分 PDF；遇边界错误查整卷原件。不能确认的具体说法不进入已核实讲解，记录缺口。
3. 在对应表中仅将本次确认的具体范围记为已核实，注明小节、印刷页码、拆分 PDF 页序和核实内容；不升级整章其他候选。教材输入不修改。
4. 使用 `lessons/<ID>.md`，遵守 FORMAT。以学生自主学习组织：先预测或观察，操作具有教学意义的图表，用简短解释与必要公式建立因果关系，再指引阅读教材具体小节并将 Quiz 集中在章末。主线连续下拉阅读，不提供步骤切换。主线依据 Volume1–3，Ref 中更好或更新的解释放入可点击 details 知识卡片，不写两本书怎样互补的教学管理说明。已有辐射/热统基础的学生应保留定量关系、推导入口和适用边界。Quiz 默认单选和判断，条件充分，只有一个正确选择，解析说明常见误解并指向正文块。
5. 不联网搜索科学进展。模型已有知识仅触发“可能过时、尚未核查”；写清待核查原说法的位置、关键词、适合查阅的来源类型与提交要求。不要凭记忆宣布某任务取消、已发布某数据或解决某争议；不要编造论文或链接。Ref 已有充分解释时用知识卡片解决；仍无解释且有教学价值的缺口才设开放调研。不要把“可能过时”强行转换成每节必有的问题。
6. 生成原创教学解释与原创示意图，公开输出不含教材全文/截图/长摘录/本地路径。复用符合物理问题的活动；需要新的直观解释时可扩展组件，不让现有模板限制内容。数字曲线与示意曲线必须明确区分，模型的假设、归一化、单位和非观测性质要在图旁说明。
7. 执行 `./tools/course build <ID>`、`./tools/course check`。浏览器检查图文与公式、至少一个交互、全部答案和解析、飞书反馈入口、窄屏及在线操作。纯静态检查不代表教学正确或视觉通过。
8. 交付源文件、HTML、核实范围和未解决项。课程创建不隐含 Git 提交、推送或发布授权。

一个独立 HTML 必须包含核心资源；公式使用原生 MathML，格式见 FORMAT，不留下未渲染 LaTeX。进展任务的外部参考链接可联网访问，但学习与判题不得依赖它们。

页面面向 GitHub Pages 在线自习，取消下载提示、装饰性英文、操作口号和题数宣传。反馈问卷 URL 位于 tools/feedback.json；未完成飞书授权及实际提交核验时，不声称已能收集反馈。不得在网页嵌入飞书访问密钥。

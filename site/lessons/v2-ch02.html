01

OBAFGKM 是观察路线，不是年龄表

滤光片把光谱压缩成少数读数，光谱则展开其中的细节。先问一条线在哪里、有多强、有多宽，再讨论它代表什么。

沿序列由 O 到 M，恒星总体从热、蓝走向冷、红；但某一条线并不需要单调变化。巴耳末线在 A 型附近最显著，是序列中间的特征，不是最热端的特征。

沿光谱序列寻找“谁最显眼”

从 O 移到 M：巴耳末线是否一直增强？先看特征，再判断温度方向。

吸收凹陷是为比较特征而构造的示意，不是实测或大气模型合成谱；深度不用于丰度反演，线宽也不编码光度级。

在热端注意氦的特征；从 A 往较冷端，许多金属线变得显眼；冷端还可出现分子带。天文学中的“金属”泛指比氦重的元素，不是化学课上的金属分类。

早型与晚型只指序列位置，不说明一颗星年轻或年老。 判断年龄需要额外的演化信息。

Ref 知识卡片 · 为什么会有吸收线，而不只是整条谱一起变暗？

Ref §5.1 与 §8.1 从原子能级和谱线形成解释选择性吸收。只有满足能级差的光子能触发相应跃迁；要形成某条吸收线，粒子还必须处在该跃迁的下能级。

“较热连续光源前的较冷气体”是理解吸收谱的起点。真实恒星大气中，不同波长来自不同深度，线与连续谱的对比还取决于温度梯度和辐射转移；不要把这幅薄屏图景当成完整大气模型。

02

为什么氢多，也未必有强氢线？

巴耳末线吸收的下能级人口由 n=2 的中性氢提供。总氢核很多，只满足了“原料充足”；还要过两道门：电子没有被电离出去，而且处在正确的激发态。

低温时，中性氢可以很多，但绝大部分留在基态；升温有利于进入 n=2。继续升温，电离又减少了可用的中性氢。两种趋势竞争，给出中间温度的高峰。

Ref 知识卡片 · 用玻尔兹曼与萨哈关系把“两道门”算出来

Ref §§8.1.3–8.1.5 把激发和电离合起来讨论。玻尔兹曼关系给出同一电离级内的占据数比：

N₂/N₁ = (g₂/g₁) exp[−(E₂−E₁)/(kT)]

氢的 n=2 与 n=1 能级差约 10.2 eV，简化统计权重比为 4。萨哈关系进一步给出电离级比例：

N_II/N_I = [2Z_II/(nₑ Z_I)] (2πmₑkT/h²)³ᐟ² exp[−χ/(kT)]

下面采用 LTE 理想气体、两式一致保留 n=1、2，取 Z_I=2[1+4exp(−10.2 eV/kT)]、Z_II=1。低激发极限下 Z_I≈2，萨哈式前面的 2 与该基态权重约分。χ≈13.6 eV。三个读数分别显示中性比例、中性氢内部激发比例，以及两者的乘积。配分函数截断与外加电子密度是教学近似；这里不是固定总氢密度下联立电荷守恒的大气求解。改变电子密度时，每条曲线都按自己的峰归一化，只能由读数比较绝对占比。

两道门：先留住电子，再把它激发

升温一面帮助激发，一面促进电离。n=2 占全部氢核的比例，会一直上升吗？

LTE 理想氢示意：两式一致截断到 n=1、2，曲线各自按峰归一化。外加电子密度的参数扫描，不是固定总氢密度下的自洽大气；n=2 占比不是等值宽度。

这里算的是粒子占据数，不是线的等值宽度。真正的线强还取决于柱密度、连续不透明度、展宽和转移。请不要把图上峰温直接当成某一光谱型的精确温标。

03

从辨认谱型，到避免丰度误判

若两颗星的铁线深度不同，先别写“铁含量不同”。试着列出同样会改变线强的条件：温度改变激发和电离；压强与电子密度改变粒子状态；大气分层与连续吸收改变对比；展宽改变线形。

更可靠的思路是：先约束大气参数，再把多条线与有条件的模型比较。用“一条线越深，元素就越多”代替这条分析链，会把状态变化误认成成分变化。

Ref 知识卡片 · 光谱型之外，还有光度级

Ref §8.2 的 MK 分类用另一个维度描述光度级。类似的温度序列位置，并不保证相同半径、表面重力与线形。把温度特征和重力相关特征分开看，有助于理解为什么不能仅凭一个谱型字母解决全部大气参数。

本页光谱图没有编码光度级或展宽效应；它只演示温度序列中的典型特征。

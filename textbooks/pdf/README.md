## 缺教材时

Agent 先检查本次实际需要的卷和版本；缺少时明确向当前用户索取该 PDF。用户可提供本地文件或通过所用 Agent 的附件入口提供；确认能读取后放到表中位置。只补本轮需要的材料，不先要求全部齐备。若同名文件已存在，先核对内容和版本，不自动覆盖。

文件名只是位置约定。首次读取仍须确认书名、卷号、版本与语言，实际打开相关章节，检查正文与公式页面可读。扫描版可使用当前环境可用的 OCR 辅助定位，公式、数字和图表须核对实际页面；识别不清时报告缺口，不凭记忆补全。

## 核实与引用

以原版为关键科学判断依据，译本帮助理解；Ref 只在确需补充时读取。记录实际使用版本、小节、印刷页码或 PDF 页序，说明页码种类，不假定原版和译本页码一一对应。没有英文 Ref 时如实引用中文版本，争议无法解决则交助教。

不依赖旧 MinerU、拆分 PDF 或 mapping 对应表。教材保持只读；译本内容修订由助教使用教材修订流程处理。公开 PR 只写书目定位、自己的解释和必要证据概述，不上传教材、截图或长摘录。
